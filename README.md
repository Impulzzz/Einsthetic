**Einsthetic** is an intelligent AI-powered platform designed to help Computer Science students master the GATE exam. It features infinite question generation using **Groq AI (Llama-3)**, real-time analytics, and a modern glassmorphism UI.

## ✨ Key Features

- **Infinite Practice Loop**: Generate unique MCQ and NAT questions for any CS subject on demand.
- **AI-Powered Explanations**: Detailed, step-by-step solutions for every question.
- **Smart Analytics**: 
  - Radar charts for subject proficiency.
  - Line charts for tracking daily preparation consistency.
- **GATE Standard**: Questions curated to match the difficulty of the actual exam.
- **Modern UI**: Dark-mode first design with glassmorphism, animations, and responsive layout.

## 🛠️ Tech Stack

- **Backend**: Python, Flask, Groq API (Llama-3-70b)
- **Frontend**: HTML5, TailwindCSS, Vanilla JS, Chart.js, MathJax
- **Database**: Firebase Firestore (NoSQL)
- **Authentication**: Firebase Auth
